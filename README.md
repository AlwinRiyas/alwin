## Local preview

This is a static site. You can preview it with any local HTTP server.

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Deployment

The repository is prepared for static hosting such as GitHub Pages. The production canonical URL in the HTML, `robots.txt`, and `sitemap.xml` must be changed from the placeholder domain to the actual deployed domain before publishing.
