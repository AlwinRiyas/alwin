02 / SECURITY ENGINEERING

Odin

A modular security-scanning CLI with risk scoring, controlled checks, and structured reporting.

PythonCLIScanningRisk ScoringSARIF
OVERVIEW

Odin is designed as a modular security-scanning workflow. Its architecture separates scanning, analysis, risk scoring and reporting so security checks can evolve without turning the CLI into a monolith.

SCAN → ANALYZE → SCORE
→ JSON / HTML / SARIF
CAPABILITIES

SCANNERS

Passive scanners and controlled active checks organized as modular components.

RISK

Findings are evaluated and presented through risk-oriented results.

REPORTING

Terminal output plus structured JSON, HTML and SARIF reporting.

ENGINEERING

A security workflow designed to be extended.

The project emphasizes modularity, profiles, quality gates, packaging, documentation and automated testing.

Its portfolio case study will evolve as new scanners, reporting capabilities and hardening work are added.
