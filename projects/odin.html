Odin

A modular security-scanning CLI with risk scoring, controlled checks, and structured reporting.

OVERVIEW

Odin 0.9.0 is designed as a modular security-scanning workflow. Its architecture separates configuration, scanning, finding normalization, risk analysis and reporting so security checks can evolve without turning the CLI into a monolith.

→ JSON / HTML / SARIF

CAPABILITIES

SCANNERS

Seven documented passive modules: cookies, CORS, disclosure, headers, HTTP, methods, and TLS.

RISK

Findings are evaluated through risk and severity scoring, with configurable failure thresholds.

REPORTING

Terminal output plus structured JSON, standalone HTML and SARIF 2.1.0 security-results output.

ENGINEERING

A security workflow designed to be extended.

The project emphasizes modularity, profiles, quality gates, packaging, documentation and automated testing.

Active scanning is explicitly policy-controlled and disabled by default, with a bounded request budget for authorized assessment environments.
