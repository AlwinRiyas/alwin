Veritas

File Integrity Monitoring focused on detecting unauthorized changes and producing security-relevant evidence.

PythonCLISHA-256Security
OVERVIEW

Veritas establishes a trusted file baseline and monitors files for changes. It is designed around integrity verification, change detection, security logging, input validation, symlink protection, resource controls, and testing.
